# ruml
Generate plantuml code from rust code

## To build ruml
VS Code - https://code.visualstudio.com/download

Rust in Visual Studio Code - https://code.visualstudio.com/docs/languages/rust

*Note:* launch.json has an INPUT parameter that will be sent to ruml

## To view generated UML you need the following

PlantUML (VS Code extension) - (Ctrl+P) `ext install plantuml` or https://marketplace.visualstudio.com/items/?itemName=jebbs.plantuml

Java - http://java.com/en/download/

Graphviz - https://www.graphviz.org/download/

*Note*: When viewing large PlantUML diagrams, it's recommended to export to SVG then view in a browser for better performance and CTRL-F functionality.
